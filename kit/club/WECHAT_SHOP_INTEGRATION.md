# SAGI CLUB SHOP × 微信小店对接方案（TARLAN FC 试点）

## 当前结论

TARLAN FC 第一家试点不再把“预售”作为唯一前提。

优先验证微信小店的 **支持定制** 功能：

- 商品：TARLAN FC 2026 主场比赛套装
- 尺码：作为 SKU 规格
- 球员姓名：文字定制
- 球衣号码：文字定制
- 发货：使用微信小店后台允许的“定制订单发货时效”
- 履约：SAGI 接单 → 核验 → 原工厂补单 → SAGI 统一发货

公开规则资料显示，微信小店“支持定制”功能可让买家填写文字/图片定制内容，并让定制订单按商家设置的定制发货时效履约；资料记载最长可设置 15 天。正式上线前必须以当前微信小店后台实际显示的能力为准。

## 后台验证路径

1. 商品管理 → 新增商品
2. 类目：运动户外 → 运动服饰 → 套装 → 足球服套装
3. 更多设置 → 支持定制
4. 验证是否可选择：
   - 文字定制
   - 定制预览
   - 定制后发货时间
5. 尺码作为 SKU：
   - S / M / L / XL / 2XL ...（以工厂真实尺码表为准）
6. 文字定制：
   - 球员姓名
   - 球衣号码
7. 上传定制说明图（如后台支持）
8. 设置物流模板与 SAGI 发货地址
9. 先做 1 笔测试订单，不立即公开推广

## 2026 新增补充能力

微信小店在 2026-10-26 公布“标记定制订单”能力，可用于将未发货的非标准实物定制订单标记为定制订单，并补充定制信息。该能力主要解决定制订单标识/售后管理，不应被当作虚假延迟发货工具。

## 上线闸门

以下全部通过后才允许把 SAGI KIT 的购买按钮打开：

- [ ] 足球服套装类目审核通过
- [ ] 商品编辑页确认出现“支持定制”
- [ ] 姓名/号码可正常填写并在订单详情显示
- [ ] 定制发货周期满足原工厂生产时间
- [ ] 测试订单付款成功
- [ ] SAGI 后台能看到定制内容
- [ ] 测试订单完成真实物流发货
- [ ] 售后/退款规则已写清

## 不采用的做法

- 虚报现货库存
- 付款后伪造物流
- 用普通 48 小时现货订单承接 7–15 天生产
- 为规避平台规则把微信小店订单引导到站外付款
