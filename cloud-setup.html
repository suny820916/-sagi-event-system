云端数据库 + 多设备同步 + 公开赛事页 + vMix

一次性云端配置

1
创建 Supabase 项目
进入 Supabase Dashboard，新建一个项目。项目创建完成后打开 SQL Editor。
2
运行 SAGI 数据库脚本
复制下面全部 SQL，粘贴到 SQL Editor，然后点击 Run。只需要执行一次。
3
找到两个参数
在 Supabase 的 Connect / Settings → API Keys 中找到：Project URL，以及 Publishable Key（以 sb_publishable_ 开头）。不要使用 Secret Key。
4
回到 V2.0 → 工具 → 云端同步中心
填 Project URL、Publishable Key、赛事代码，再设置一个至少8位的写入密码。点击“连接 / 创建云赛事”。第二台手机只需要填同一组信息，就会连接同一个赛事。
5
公开赛事页与 vMix
管理端可以直接复制两个链接。公开赛事页只读；vMix 中添加 Browser Input，把 vMix 链接粘进去，建议分辨率 1920×1080、背景透明。
打开 V2.0 管理端打开公开页

数据安全

Publishable Key 本来就是用于浏览器端的公开低权限 key；赛事写入权限另外由你的 SAGI 写入密码校验。不要把 Supabase Secret Key 填进网页，也不要发给任何人。
