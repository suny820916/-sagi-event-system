# SAGI POOL LIVE · CHINA V2.0

面向中国大陆球房销售的手机台球直播与自动记分系统。

## 已完成

- 中式八球抢局计分
- 4球 / 6球 / 9球追分
- 2–4人追分
- 普胜 / 小金 / 大金 / 黄金9 自定义分值
- 赢家加分 / 输家等额扣分两种结算
- 当前击球球员、犯规、8号球犯规
- 撤销、新一局、比赛归零、比赛日志
- 手机前后摄像头直播预览
- SAGI 赛事级比分牌与事件动画
- 球房名称、球桌编号品牌化
- 1–12桌球房控制台
- 每桌独立数据与独立入口
- 专用第二手机直播屏
- PWA 桌面安装与离线缓存
- 国内多手机同步接口
- 零第三方依赖 SAGI CHINA SYNC 服务
- GitHub Actions 自动自检 + 国内同步端到端测试

## 页面入口

- 记分端：`/sagi-pool-live/`
- 球房控制台：`/sagi-pool-live/club.html`
- 直播手机：`/sagi-pool-live/live.html`

## 国内部署

`china-sync/` 是纯 Node.js 服务，不依赖 Supabase、Firebase、Cloudflare 等海外 BaaS。

推荐正式商用部署到：
- 腾讯云轻量应用服务器 / CVM
- 阿里云 ECS

正式域名使用中国大陆服务器时，需要按规定办理 ICP 备案并配置 HTTPS。

## 当前边界

V2.0 已经实现“记分手机 → 国内服务器 → 直播手机 / 球房控制台”的实时比分数据链路。

真正把摄像头画面编码并直接推送到抖音、视频号等平台，需要下一层原生移动端 LIVE ENGINE。国内路线优先 Android + 阿里云/腾讯云直播推流 SDK，不把核心推流能力寄托在手机浏览器。
