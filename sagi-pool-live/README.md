# SAGI POOL LIVE · CLUB

手机端球房直播记分产品 MVP。

## V1.3 已完成
- 中式八球抢局计分
- 4球 / 6球 / 9球追分
- 2–4人追分
- 普胜 / 小金 / 大金 / 黄金9 可自定义分值
- 两种追分结算方式
- 手机后置/前置摄像头预览
- 赛事级直播比分包装与事件动画
- 撤销、犯规、新一局、比赛归零
- 本地自动保存与比赛日志
- PWA 安装与离线缓存
- 球房名 / 球桌编号品牌化
