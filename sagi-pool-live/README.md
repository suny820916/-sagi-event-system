## 中国大陆服务端

`china-sync/` 是零第三方运行时依赖的 Node.js 服务，可部署到腾讯云轻量应用服务器 / CVM 或阿里云 ECS。

正式商业模式建议环境变量：

```bash
PORT=8787
SAGI_REQUIRE_LICENSE=1
SAGI_ADMIN_TOKEN=<仅SAGI掌握的管理员密钥>
SAGI_ALLOW_ORIGIN=https://你的正式域名
node server.mjs
```

使用中国大陆服务器和正式域名对外提供服务时，需要按规定完成 ICP 备案并配置 HTTPS。
