# SAGI KIT Brand Mark

## Official primary mark
The approved SAGI KIT symbol is the **A-shaped white arch + red dot**.

### Rules
- The A-shaped arch is the primary silhouette.
- The red dot is a fixed brand memory point and must not be removed in normal full-color use.
- On dark interfaces, use the white arch + red dot.
- At small sizes, use the symbol alone; do not force the full wordmark into tight spaces.
- "SAGI KIT" is a product/business name next to the mark, not a replacement for the mark.
- Customer-facing KIT pages must not display factory/supplier marks as SAGI branding.
- Supplier names, source model IDs, costs, and factory contacts stay outside the public customer bundle.

### Core placements
1. Mobile launcher/header
2. Customer selection flow
3. Customer confirmation sheet
4. Order history/workflow center
5. Admin import bridge
6. Cloud backup settings
7. Future jersey chest mark / shorts mark / neck mark / packaging

### Color
- Arch: #FFFFFF on dark surfaces
- Dot: #FF1717
- Dark background recommendation: #080A0D
