# SAGI HOUSE V1.0

手机优先的本地房源与客户线索平台。

## V1.0 功能
- 房源首页与搜索/筛选
- 房源详情
- 手机发布房源
- 手机照片压缩
- 客户咨询留资
- 线索工作台与 CSV 导出
- PWA / 添加到手机桌面
- 离线缓存

## 当前数据模式
V1.0 使用浏览器 localStorage，适合作为可运行 MVP。  
V1.1 计划接入 Supabase：统一房源库、多人/多设备同步、登录、图片存储和云端线索。
