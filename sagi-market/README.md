# SAGI MARKET 工作台 V1.1

定位：SAGI 足球闲置与拼团中心的内部交易工作台，不是消费者 App。

## 三条业务线
- SECOND LIFE：闲置寄售
- TEAM BUY：球队拼团
- SAGI DEAL：限时好价

## V1.1 能做什么
- 自动商品编号：SG-S001 / SG-T001 / SG-D001
- 商品照片本机保存（IndexedDB）
- 业务数据离线保存（localStorage）
- 待审核 / 在售 / 已成交 / 已发货 / 已结算 / 已取消
- 自动计算闲置寄售佣金
- 自动计算球队拼团毛利
- 首页待处理任务
- 商品搜索、业务筛选、状态筛选
- 拼团目标数量与当前数量进度
- 成交额、SAGI收入、待给卖家、已结算
- 一键标记卖家已结算
- 自动生成商品发布文案
- 自动生成 1080×1350 SAGI 商品卡 PNG
- CSV 交易导出
- JSON 完整备份/恢复（含本地照片）
- PWA，可添加到手机桌面
- 首次打开后可离线使用

## 默认佣金规则
- 售价 < 100 元：固定 10 元
- 100–299 元：15%
- 300 元及以上：10%

工作台内可直接修改。

## 数据说明
V1.1 是“先跑业务”的内部版本，数据保存在当前设备浏览器，不依赖服务器。
因此适合一个人/一个手机先跑 30 天验证。
当业务达到稳定交易量后，再升级云端同步、多设备和微信小店订单接入。


## V1.1 SELLER INTAKE
- 卖家独立入口：seller.html
- 卖家手机上传1张主图并填写商品信息
- 图片自动压缩后提交到 SAGI CLOUD BRIDGE
- 云桥使用服务器密钥写入 Supabase 收货箱，卖家不接触管理密钥
- 工作台首页显示“云端收货箱”
- 审核通过：自动生成 SG-Sxxx 编号、写入正式商品库、状态变为在售
- 审核拒绝：不进入正式商品库
- 跨手机同步：卖家手机提交，你的手机工作台读取
- 云端不可用：卖家自动得到 JSON 提交单，可在工作台“导入离线提交单”
- 卖家入口支持分享链接与二维码
