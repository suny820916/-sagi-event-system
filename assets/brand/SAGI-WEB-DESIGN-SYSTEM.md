# SAGI FOOTBALL — WEB DESIGN SYSTEM V1.0

## Brand idea
SAGI is a football brand built around local football.

Core line:
- 为身边的足球加油
- 记录平凡人的足球梦

Brand symbol:
- The red dot means 热爱.
- A = ARDOR · AFIRE · ALIVE.
- The red dot should be visible, intentional, and rare enough to matter.

## 1. Core colour system

### Primary
- Pitch Black: #090909
- Stadium White: #F4F4EF
- Graphite: #151515
- Line Grey: #292929
- Muted Grey: #949494
- SAGI Red: #E51F2E

### Secondary / contextual
- Turf Green: #236748 — success / pitch / football utility states only.
- Heritage Gold: #B99A50 — trophies, honours, medals, championships only.

### Rule
Gold is NOT a normal navigation, button, or primary brand colour.
SAGI Red is the main brand signal and CTA accent.

## 2. Team pages
The SAGI platform shell stays black / white / SAGI red.
A club-specific page may use the club's own colours as the local accent.

Example:
- TARLAN FC: purple + pink within the TARLAN page.
- SAGI header, footer and system-level navigation remain recognisably SAGI.

## 3. Visual hierarchy
1. Football / human story first.
2. One strong headline.
3. One clear action.
4. Product or tool details second.
5. System / technical information last.

Avoid:
- Multiple stacked navigation rows.
- Large explanation cards before the actual football content.
- Decorative gold gradients.
- Dashboard-like density on public-facing pages.

## 4. Typography
- Chinese headlines: large, heavy, short.
- English: uppercase, compact, used for rhythm and category labels.
- Avoid long English marketing paragraphs.
- Keep copy football-specific and concrete.

Suggested rhythm:
- EYEBROW: 9–11px, uppercase, letter-spaced.
- H1: 48–104px responsive.
- Section title: 24–32px.
- Body: 12–15px.
- Metadata: 9–11px.

## 5. Image direction
Preferred:
- Real local football.
- Players before / during / after matches.
- Boots, grass, jerseys, sweat, hands, sidelines, floodlights.
- Real teams using SAGI.
- Wide emotional football frames + tight equipment details.

Avoid:
- Generic corporate stock.
- Over-polished luxury imagery unrelated to football.
- AI-looking players when real match imagery is available.

## 6. Shape language
- Simple rectangles and rounded cards.
- Strong whitespace / blackspace.
- Subtle football geometry: centre circle, touchline, penalty-box lines.
- Do not overuse football icons.

## 7. Interaction
Use verbs:
- 选款
- 查看款式
- 进入球队选款
- 创建赛事
- 查看直播
- 了解 SAGI

Avoid commerce language on selection-only pages:
- 购买
- 立即支付
- 下单付款

## 8. Product architecture
Public website:
- HOME — brand / football story
- KIT — teamwear selection
- EVENT — event tools
- BROADCAST — broadcast tools
- ABOUT — SAGI culture

KIT:
- 产品库
- 原版画册
- 球队选款

CLUB SHOP:
- Selection and requirement collection only.
- No online payment.
- Customer selects style, fills information, downloads order file, sends it to SAGI.

## 9. International reference principles
Borrow structure, not identity:
- Nike: campaign-led hero and minimal chrome.
- adidas: clear product / team task grouping.
- PUMA: short, high-energy football language.
- Macron: teamwear workflow and club-specific customization.

SAGI remains visually distinct through:
- red dot
- local-football storytelling
- black / white restraint
- ARDOR · AFIRE · ALIVE
