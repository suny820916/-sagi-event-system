# SAGI MATCH PHOTO V1.1 · DOWNLOAD CODE FLOW

总决赛现场目标：跑通 **拍摄 → 上传 → 水印预览 → 选图 → 生成订单 → 微信单独付款 → 管理员生成下载码 → 用户在 SAGI KIT 输入下载码 → 下载高清原图**。

## 支付原则
- 网页 / 小程序 **不接支付接口**
- 不展示微信收款码
- 用户与 SAGI 通过微信单独完成付款
- 管理员确认到账后，点击“已收款 · 生成下载码”
- 下载码格式为人类易输入的 10 位码，例如 `ABCDE-23456`
- 用户只需要下载码，不需要再输入订单号
- 普通订单接口不会返回下载码；只有管理员接口能看到下载码

## 总决赛现场流程
1. 管理端创建“托朗戈杯总决赛”。
2. 每场结束后批量上传精选照片，填写球队 / 场次 / 号码。
3. 球员或家长从 SAGI KIT → MATCH PHOTO 找照片。
4. 选图并生成订单，页面显示订单号和金额。
5. 用户微信单独付款，把订单号发给 SAGI。
6. 管理员确认到账，点击“已收款 · 生成下载码”。
7. 将下载码发给用户。
8. 用户在 SAGI KIT 输入下载码，出现高清原图下载按钮。

## 国内使用
生产环境不依赖网页内微信支付，也不依赖海外支付回调。

前端可以继续放在 SAGI KIT；照片服务建议使用在中国大陆访问稳定、支持持久对象存储的后端。正式比赛照片不能依赖临时磁盘。

需要的环境变量：
- `ADMIN_KEY`：管理员密钥
- `DATA_DIR`：持久数据目录（仅文件系统部署时）
- `ALLOWED_ORIGINS`：允许访问 API 的 SAGI 域名列表
- `PUBLIC_TITLE`：公开标题
