# SAGI MATCH PHOTO V1.0 · EVENT REVENUE MVP

目标：总决赛现场先跑通 **拍摄 → 上传 → 水印预览 → 选图 → 微信收款 → 管理员确认 → 无水印原图下载**。

## 已完成
- 手机优先 PWA，可从手机主屏幕打开
- 赛事创建
- 一次最多 40 张批量上传
- 服务器自动生成 SAGI 水印预览，不公开原图地址
- 赛事 / 球队 / 球衣号码检索
- 多选购物车与自动优惠：¥5 / ¥15(最多5张) / ¥29(最多20张) / ¥99
- 订单生成
- 手工微信收款确认
- 支付确认后生成随机下载令牌
- 管理端可在同一手机网页完成创建赛事、上传、确认收款
- PWA 离线壳
- Render Blueprint + 持久磁盘配置
- Node 内置价格测试

## 总决赛建议流程
1. 管理端创建“托朗戈杯总决赛”。
2. 每场结束后从手机批量上传精选照片，填写球队/场次；如果能识别号码，再填球衣号码。
3. 现场二维码指向公开首页，文案：**找到你的高光时刻｜扫码查看比赛照片**。
4. 球员/家长选图生成订单并微信付款。
5. SAGI 管理端看到订单后点击“确认已收款”。
6. 买家刷新订单即可逐张下载高清原图。

## 上线前必须配置
- `ADMIN_KEY`：必须替换默认值。
- `DATA_DIR`：生产环境使用持久磁盘。
- `PAYMENT_QR_URL`：可选，配置 SAGI 微信收款码的 HTTPS 图片地址。
- `PAYMENT_MODE=manual`：总决赛首版采用人工核款；没有微信商户号也能收钱。
