SAGI BROADCAST · Windows x64 验收构建

解压整个文件夹到本机。打开 Start SAGI Broadcast.cmd。
首次启动填写主队和客队。手机要访问时填写本机 LAN 地址，
让手机连接同一网段，并在桌面批准配对。vMix 输入使用窗口显示的浏览器输入地址，再点击「显示比分牌」。
比赛数据位于当前用户的 %LOCALAPPDATA%\SAGI Broadcast\Match。

本构建供验收使用。当前手机 HTTP 仅用于可信测试局域网。
桌面重启后请从窗口取得本次启动的浏览器输入地址。
runtime\LICENSE 随 Node.js 运行时提供。ZIP 的 SHA-256 用来核对传输完整性。
