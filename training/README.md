# SAGI TRAINING V1.0
手机优先、全中文、本地优先的足球运动员成长系统。
独立分支，不修改直播稳定主线。
## MVP
- 球员档案（昵称、年龄段、位置；未成年人最小化数据）
- 训练动作库、每日任务、训练打卡
- SAGI STANDARD 原始成绩、测试协议版本、复测趋势
- 教练管理与数据导出、删除
- AI颠球计数实验：固定机位，人工校验，不将未验证成绩作为正式成绩
## 验收
- iOS Safari 手机主屏幕入口与离线基础功能
- 刷新、重启后数据恢复；导出/导入往返验证
- 无外网服务依赖的核心功能
- 年龄适配、训练负荷人工审核；不做伤病诊断
- AI计数以人工标注视频验证，公开误差与失败条件
- 开源依赖商用许可审计；视频默认不上传
## 研发顺序
档案与训练记录 → 测试复测 → 教练管理 → AI计数 → 实机验收。
未经实机验证不得标记为商业稳定版。
