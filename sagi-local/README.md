# SAGI AI LOCAL V1.3 · DESIGN SYSTEM

V1.3 不再使用单一“照片 + 底部渐变 + 标题”模板。

## 三套商业设计系统
- EDITORIAL：全幅商业摄影 + 杂志式层级 + 大留白 + 金色节奏线
- BRAND SPLIT：照片区 / 品牌信息区分栏，更接近品牌Lookbook和产品广告
- IMPACT：高对比、斜切标签、强利益点，适合促销、团购和强转化内容

## 共同能力
- 3:4 商业海报
- 9:16 短视频封面
- 自动识别“¥ / 元 / 折 / 第二份半价 / 买一送一”等利益点并强化
- 根据模板采用不同的色彩、构图、标题层级、CTA和信息密度
- 三模板可在同一张照片上即时切换对比
- AI在线时继续先做商业底图编辑，再进入SAGI版式系统
- AI离线时仍可本地生成三套完整海报

## 原则
不是“生成一张能看的图”，而是建立可以不断扩展的 SAGI 商业视觉模板库。
