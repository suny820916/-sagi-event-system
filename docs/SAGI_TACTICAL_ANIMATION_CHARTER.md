==================================================
一、项目的唯一使命
==================================================

建立一套专业足球战术动画生产系统。

让用户能够输入真实足球比赛素材，经过战术分析、动作确认、导演设计和动画渲染，最终制作出专业级足球战术动画。

最终目标：

输入真实比赛视频
→ 识别比赛动作
→ 分析战术关系
→ 建立真实事件时间轴
→ 生成导演方案
→ 3D球员动画
→ 足球运动与触球
→ 摄像机导演
→ 渲染
→ 自动验收
→ 输出专业战术动画。

项目不是普通视频剪辑工具。
不是足球海报生成器。
不是战术箭头绘图工具。
不是简单的3D球员移动演示。

它必须成为真正理解足球空间、球员关系、动作时序和战术因果的动画制作系统。

唯一视觉和导演标准：

TEACTICS。

不允许擅自更换参考标准。

六、球员动作是当前最重要的升级方向
==================================================

当前最需要突破的不是继续增加镜头和图形。

而是让球员真正像足球运动员。

逐步建立统一动作库：

IDLE
SCAN
TURN
JOG
SPRINT

DECELERATE
RECEIVE
ONE_TOUCH
PASS
CROSS
CUTBACK
SHOOT
DEFENDER_SHIFT
PRESS
RECOVERY_RUN
GOALKEEPER_REACTION

每种动作必须具有：

- 正确身体姿态
- 合理运动速度
- 身体重心变化
- 动作起始与结束
- 连续动作衔接
- 合理的身体反应
- 与足球运动的时间同步

优先研究骨骼Rig、IK、足底接触、动作捕捉等技术。

不要无限依靠简单几何体摆动来改善动作。

每项升级都必须有可运行的动作测试。

七、足球与触球系统
==================================================

这是第二个最高优先级。

- 支撑脚位置

- 接球缓冲
- 球员调整身体
- 射门动作
- 球的速度和轨迹
- 门将反应

禁止球瞬间传送。

禁止球员没有触球动作，足球却自行改变方向。

禁止球与球员身体穿透。

建立独立的BALL CONTACT测试。

==================================================
十一、质量验收
==================================================

所有交付必须通过三个独立门槛。

GATE A：技术质量

- 能否正常渲染。
- 是否存在黑帧。
- 是否丢失球员。
- 是否丢失足球。
- 是否存在闪烁。
- 是否出现穿模。
- 是否能完整解码。
- 是否输出正确分辨率。

GATE B：足球真实性

- 球员位置是否准确。
- 触球顺序是否准确。
- 传球是否准确。
- 跑位是否准确。
- 防守反应是否合理。
- 进攻因果是否成立。

GATE C：Teactics视觉质量

- 人物是否自然。
- 空间是否清楚。
- 镜头是否有导演感。
- 焦点是否准确。
- 微时序是否自然。
- 节奏是否合理。
- 整体质感是否接近参考样片。

三个门槛必须分别报告。

GitHub Actions绿色不能代表视觉验收通过。
